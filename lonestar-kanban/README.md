# Lone Star College RFCQ 26-05-03 — Shared Kanban

Interactive Kanban board for managing the Lone Star College RFP response.

## Features
- **Shared state** — both team members see the same board in real-time
- **Drag & drop** cards between Backlog → In Progress → Completed
- **Add/edit/delete** cards with modal editor
- **Checklist** with clickable checkboxes for signature/action items
- **Auto-refresh** every 15 seconds
- **Dark theme** — easy on the eyes
- **Mobile responsive**

## Deployment
1. Push this repo to GitHub
2. Import into Vercel (vercel.com)
3. Vercel auto-deploys — get a URL like `lonestar-kanban.vercel.app`
4. Share the URL with your teammate

## Tech
- Frontend: Vanilla HTML/CSS/JS (no frameworks)
- Backend: Vercel serverless function (Node.js)
- Hosting: Vercel (free tier)
