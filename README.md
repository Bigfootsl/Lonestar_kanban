## Deploy to GitHub + Vercel (step by step)

### Step 1 — Create a GitHub repository

1. Go to [github.com](https://github.com) and sign in (create a free account if you don't have one).
2. Click the **+** icon in the top-right corner → **New repository**.
3. Name it something like `rfcq-26-05-03-tracker`.
4. Leave it **Private** if you only want invited collaborators to see the source code; the live site will still be publicly accessible.
5. Do **not** initialize with a README (you already have one).
6. Click **Create repository**.

### Step 2 — Upload the project files to GitHub

**Option A — drag-and-drop in the browser (easiest)**

1. On the empty repo page, click **uploading an existing file**.
2. Drag all four files (`index.html`, `vercel.json`, `.gitignore`, `README.md`) into the upload area.
3. Scroll down, add a commit message like `Initial commit`, and click **Commit changes**.

**Option B — GitHub Desktop app**

1. Download [GitHub Desktop](https://desktop.github.com/) if you haven't already.
2. Clone the new repository to your computer: **File → Clone repository**.
3. Copy the four project files into the cloned folder.
4. In GitHub Desktop, review the changes, write a summary, and click **Commit to main**.
5. Click **Push origin**.

**Option C — command line**

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/rfcq-26-05-03-tracker.git
git push -u origin main
```

### Step 3 — Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) and sign in with your GitHub account (creates a free account automatically).
2. Click **Add New… → Project**.
3. Under "Import Git Repository," find `rfcq-26-05-03-tracker` and click **Import**.
4. Vercel auto-detects this as a static site. You don't need to change any settings.
5. Click **Deploy**.

Vercel will build (takes about 10 seconds) and give you a live URL like:

```
https://rfcq-26-05-03-tracker.vercel.app
```

Share that URL with your team. Anyone who opens it gets the board with all default tasks pre-loaded in their browser.

### Step 4 — Share a specific board state

The "Share Board" button inside the app generates a URL with the current board state encoded in the address bar (`#…`). Send that URL to a collaborator and they'll see your exact card positions, notes, and progress.

## How the app works (technical notes)

- **No backend.** Everything runs in the browser. Cards are stored in `localStorage` so each user's progress persists across page refreshes on their own device.
- **State sharing.** The "Share Board" button encodes the full board state as base64 JSON in the URL hash. Sharing that URL lets collaborators import your current snapshot.
- **No build step.** `index.html` is the complete app. You can open it directly in a browser (`File → Open`) without any server.
- **Countdown timer.** The header displays a live countdown to the May 28, 2026 10:00 AM CT deadline.

## Customizing the board

Open `index.html` in any text editor and find the `DEFAULTS` array near the top of the `<script>` block. Each object in the array is a card:

```js
{ id:'1', col:'todo', title:'...', desc:'...', cat:'...', priority:'high', due:'2026-05-28', assignee:'SK' }
```

Edit, add, or remove entries there to change the starting cards. After saving, commit and push to GitHub — Vercel will redeploy automatically.
